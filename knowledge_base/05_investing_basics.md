# Investing Basics and Risk

## Principles
Investing involves uncertainty, possible loss of principal, inflation risk, liquidity risk, credit risk, interest-rate risk, concentration risk, currency risk and behavioural risk.

## Risk and time horizon
Match instrument risk and liquidity to the goal date. Money needed soon should not automatically be placed in volatile assets.

## Compounding
`FV = PV × (1+r)^t` for annual compounding.
Compound annual growth rate:
`CAGR = (Ending value / Beginning value)^(1/years) − 1`.
CAGR describes a historical or hypothetical annualised rate; it does not guarantee future performance.

## Diversification
Diversification reduces concentration in one asset, issuer, sector or geography but does not eliminate market loss.

## Return measures
- absolute return = `(ending value − beginning value) / beginning value × 100`
- holding-period return should include relevant cash flows and costs
- XIRR is suitable for irregular cash flows; explain that software implementation must use dated cash flows
- nominal return does not account for inflation; post-tax return may differ materially

## Behavioural safeguards
Avoid performance chasing, leverage without understanding, guaranteed-return language for market-linked products and recommendations based only on past returns.
