# Financial Goals and Planning

## Goal categories
- short term: generally within 1–3 years
- medium term: approximately 3–7 years
- long term: usually beyond 7 years
These are planning labels, not regulatory definitions.

## Goal gap
Goal gap = target future value − current earmarked assets' future value.

## Future value
For a single investment with periodic compounding:
`FV = PV × (1 + i)^n`

For contributions made at the end of each period:
`FV = PMT × [((1+i)^n − 1) / i]`
If i = 0: `FV = PMT × n`.

For contributions made at the beginning of each period, multiply the ordinary-annuity result by `(1+i)`.

## Required periodic contribution
`PMT = FV × i / ((1+i)^n − 1)`
If i = 0: `PMT = FV/n`.

## Inflation-adjusted target
`Future target = current target × (1 + inflation)^years`.
Use scenarios rather than one guaranteed inflation assumption.

## Planning process
1. Define amount, date and purpose.
2. Estimate inflation and taxes.
3. Identify current resources.
4. Select risk-appropriate instruments.
5. Stress-test lower returns, higher inflation and delayed income.
6. Review periodically.

Do not call a goal achievable only because a fixed arbitrary percentage of savings is available. Compare required contribution with verified surplus and include a buffer.
